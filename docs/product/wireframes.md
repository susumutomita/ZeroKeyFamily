# 画面ワイヤーフレーム

主要画面の構成と表示要素の正本。文言は [安全文言ガイド](./safety-copy-guide.md) に従う。高齢者の可読性を優先し、主要情報はスクロールなしの一画面に収める。

正本 Issue: https://github.com/susumutomita/ZeroKeyFamily/issues/3

## W-01 ホーム

```text
+----------------------------------------+
| ZeroKey Family                          |
+----------------------------------------+
| [大ボタン] 家族に確認をお願いする        |
|                                        |
| [大ボタン] 困ったとき（緊急停止・相談）  |
+----------------------------------------+
| 最近の確認                              |
|  ・息子（太郎さんの端末）が拒否  6/9    |
|  ・娘（花子さんの端末）が承認    6/2    |
+----------------------------------------+
| 家族の管理 | 設定 | 履歴                |
+----------------------------------------+
```

- 「困ったとき」は常時ホームの第 2 ボタンに置き、深い階層に隠さない。
- 履歴の主語は人名ではなく「（人名）さんの端末」とする。

## W-02 確認要求の作成

```text
+----------------------------------------+
| 家族に確認をお願いする                  |
+----------------------------------------+
| だれに確認しますか                      |
|  ( ) 太郎（息子）   ( ) 花子（娘）      |
+----------------------------------------+
| 何についての確認ですか（必須）          |
|  [ お金を送ってほしいと言われた ▼ ]    |
| 金額（必須）        [        円 ]      |
| 送金先（必須）      [             ]    |
| 理由（必須）        [             ]    |
| 回答期限            [ 30 分 ▼ ]        |
+----------------------------------------+
| 注意: 金額・送金先・理由が空のままでは  |
| 確認をお願いできません。                |
+----------------------------------------+
| [ 確認をお願いする ]（必須項目入力まで  |
|   押せない）                            |
+----------------------------------------+
```

- 金額・送金先・理由は必須。未入力時は送信ボタンを無効化し、省略経路を設けない。
- プリセット文（「お金を送ってほしいと言われた」等）で入力負荷を下げる。

## W-03 確認要求の受信（承認画面）

```text
+----------------------------------------+
| ⚠ 確認のお願いが届いています            |
+----------------------------------------+
| お母さん（佐藤良子さんの端末）からの    |
| お願いです。                            |
|                                        |
|   内容: お金を送ってほしいと言われた    |
|   金額: 300,000 円                     |
|   送金先: ○○銀行 1234567               |
|   理由: 会社のお金をなくした           |
|   期限: 今日 15:30 まで                |
+----------------------------------------+
| この内容に心当たりがありますか。        |
|                                        |
| [ ▶ スライドして承認 ]（生体認証へ）   |
| [ 拒否する ]                            |
| [ 本人に電話で確かめる ]                |
+----------------------------------------+
```

- 金額・送金先・理由・依頼者を一画面に表示する。要約の省略表示を禁止する。
- 承認はスライド + 生体認証の二段階。拒否はワンタップで可能とし、拒否の方を軽くする。

## W-04 結果表示（確認済み）

```text
+----------------------------------------+
| ✓ 確認できました                        |
+----------------------------------------+
| 太郎さんの登録端末が、この内容に        |
| 同意の署名をしました。                  |
|                                        |
|   金額: 300,000 円 / 送金先: ○○銀行    |
|   署名日時: 6/10 14:55                 |
+----------------------------------------+
| これは「太郎さんの端末が署名した」      |
| ことの確認です。少しでも不安があれば    |
| 送金の前にもう一度直接話してください。  |
+----------------------------------------+
| [ 閉じる ]  [ 困ったとき ]              |
+----------------------------------------+
```

## W-05 結果表示（応答なし・期限切れ）

```text
+----------------------------------------+
| ？ まだ確認できていません               |
+----------------------------------------+
| 太郎さんの端末からの応答がありません。  |
|                                        |
| 応答がないことは、相手が本人である      |
| ことの確認にはなりません。              |
| お金を送らないでください。              |
+----------------------------------------+
| 急かされていませんか。「今すぐ」と      |
| 言われたら詐欺の可能性があります。      |
+----------------------------------------+
| [ 別の家族に確認する ]                  |
| [ 困ったとき（緊急停止・相談） ]        |
| [ 期限まで待つ ]                        |
+----------------------------------------+
```

- 成功を示す色・アイコン（緑・チェックマーク）を使わない。グレーまたは黄色系で「未確認」を表す。
- 「拒否されました」（W-06）とも視覚的に区別する。

## W-06 結果表示（拒否・検証失敗）

```text
+----------------------------------------+
| ✕ 確認できませんでした                  |
+----------------------------------------+
| （拒否の場合）                          |
| 太郎さんの端末がこの内容を              |
| 「身に覚えがない」と回答しました。      |
| お金を送らないでください。              |
|                                        |
| （検証失敗の場合）                      |
| 応答の検証に失敗しました。              |
| 安全のため、承認として扱いません。      |
+----------------------------------------+
| [ 困ったとき（緊急停止・相談） ]        |
+----------------------------------------+
```

## W-08 緊急停止

```text
+----------------------------------------+
| 困ったとき                              |
+----------------------------------------+
| [大ボタン] すべての承認を今すぐ止める   |
|   （理由の入力は不要です）              |
|                                        |
| [ 詐欺かもしれない・相談したい ]        |
|   → 警察相談専用電話 #9110 の案内      |
| [ まちがえて承認してしまった ]          |
+----------------------------------------+
| 止めたあとは、家族 2 人の操作がない     |
| 限り再開されません。                    |
+----------------------------------------+
```

- 緊急停止は確認ダイアログ 1 回のみで発動できる。理由入力を求めない。

## 共通デザイン要件

- 本文の最小フォントサイズは 17pt 相当とし、金額は 22pt 相当以上で表示する。
- 状態は色だけで区別せず、アイコン形状と文言を併用する（色覚多様性対応）。
- すべての画面で「困ったとき」への導線を 2 タップ以内に置く。
- 各 OS のアクセシビリティ機能（文字拡大・読み上げ）に追従する。
